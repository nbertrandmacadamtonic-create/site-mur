# M.U.R. — site statique

Déposer le contenu de ce dossier à la racine d’un dépôt GitHub, puis activer GitHub Pages dans **Settings → Pages → Deploy from a branch → main / root**.

La page `methode.html` contient l’étape **Utiliser** et ses quatre exercices colorés. Chaque carte s’ouvre pour afficher le contenu associé.
